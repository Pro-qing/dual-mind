## Current scope

DualMind is an unpublished development scaffold. There is no supported public release or security response SLA yet. The implemented command only displays a notification; it does not call a model, store API keys, or edit workspace files.

## Reporting

**Private reporting channel: TODO — repository owner to configure and verify.** If the repository's Security tab offers **Report a vulnerability**, use that private reporting flow. Its availability has not been assumed or enabled by the scaffold. Otherwise, request a private contact without disclosing vulnerability details in a public issue.

Include the affected commit/version, reproduction steps, impact, and relevant logs after a private channel is established. Remove credentials and personal data. Do not publish exploitable details while arranging private communication.

## Future integration

Before adding provider calls or a Webview, review credential storage, message validation, content security policy, and explicit user control over editor changes. These are implementation requirements for those features, not claims about functionality already present. Resolve contact and support commitments before public distribution.
