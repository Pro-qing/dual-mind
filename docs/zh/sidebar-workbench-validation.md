## 环境与验证范围

本机为 Ubuntu 24.04.5 x64、Node.js 24.22.3，使用真实桌面上的 VS Code 1.141.0 和下载的最低支持版本 1.100.0。测试使用隔离用户目录、临时工作区、本地模拟模型及测试凭据，没有调用付费服务。

`verify-ui.mjs` 保留双协议执行、Reviewer 独立验收、命令失败、停止、重载恢复、聊天与消息最小化回归。`verify-sidebar.mjs` 使用临时旧版扩展生成真实可序列化编辑器页签，再加载生产扩展；通过临时损坏的前端构建验证迁移失败保留页签、修复后重试，以及已有侧栏状态优先。测试不修改用户安装。

侧栏场景覆盖中英文 240／320／480／800px、草稿与阅读位置、主／辅助侧栏、位置交换、隐藏恢复、终端居中／跨窗口对齐以及窗口重载。宽度以原生侧栏边界为准，Webview 会扣除 VS Code 边框。短窗和表单操作以实际可见区域检查。
