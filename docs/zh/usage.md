# 使用说明

[English](../en/usage.md) · [文档索引](./README.md)

**当前源码版本：0.0.2 · 本地版本记录 · 尚未发布。** 本次记录日期为 2026-11-20；不表示已上传 Marketplace 或创建 GitHub Release。0.0.1 Preview 1／2 的历史发布记录保持原样。详见[0.0.2 版本说明](./release-notes-0.0.2.md)。

## 运行要求

支持基线为 **Ubuntu 20.04+、x86_64/amd64、VS Code 1.100.0+**。其他平台和 ARM64 暂未验证。从 Marketplace 或已构建的 VSIX 安装均无需另行安装 Node.js，详见[环境说明](./environment.md)。

## 从 Marketplace 安装

[Visual Studio Marketplace 上的 DualMind](https://marketplace.visualstudio.com/items?itemName=Pro-qing.dual-mind) 已于 **2026-11-18** 公开，Publisher 为 **Pro-qing**，扩展标识为 **Pro-qing.dual-mind**，版本为 **0.0.1**。在扩展面板（`Ctrl+Shift+X`）搜索 `@id:Pro-qing.dual-mind`，确认发布者和图标后点击**安装**。也可执行：

```bash
code --install-extension Pro-qing.dual-mind
```

如果安装过旧开发身份，请先按下方 Preview 1 切换说明处理，再打开新工作台。

Preview 标记表示扩展仍处于早期开发阶段。当前使用 Marketplace 普通发布通道，无需选择预发布通道。该扩展 ID 后续公开更新会递增扩展版本，用户可通过 VS Code 正常更新扩展；GitHub 同步保留对应版本的 VSIX 和校验文件。

## 下载、校验和安装 VSIX

[Preview 2 GitHub Release](https://github.com/Pro-qing/dual-mind/releases/tag/v0.0.1-preview.2) 已于 2026-11-18 发布，提供经过验证的 `Pro-qing.dual-mind` 版本 `0.0.1` VSIX 和校验文件。变更与验证记录见 [Preview 2 说明](./release-notes-preview-2.md)。

在 **Preview 2 的 Assets** 中下载 `dual-mind-0.0.1.vsix` 和 `SHA256SUMS.txt`，放到同一目录。两个预览版的文件名相同，但扩展身份及校验值不同，请使用同一 Release 的两个附件。自动生成的源码压缩包是源码快照，不是 VSIX 安装包。在下载目录执行：

```bash
sha256sum --check SHA256SUMS.txt
```

确认校验结果为 `OK`／成功后，再安装已校验的包：

```bash
code --install-extension dual-mind-0.0.1.vsix --force
```

也可通过 **Extensions: Install from VSIX...** 选择已校验文件。从源码构建请按[开发指南](./development.md)和[打包指南](./releasing.md)操作。保留的历史本地包位于 `release/dual-mind-0.0.1.vsix`，安装包及下载验证文件均不进入 Git 记录。

## 从 Preview 1 切换

旧标识 `dual-mind-dev-placeholder.dual-mind` 和新标识 `Pro-qing.dual-mind` 是不同扩展。在扩展列表搜索 `@id:dual-mind-dev-placeholder.dual-mind`，通过齿轮菜单**停用**旧扩展，重载窗口后再打开新扩展，避免重复注册命令。可以保留已停用的旧扩展安装，旧数据不会被主动删除。

新身份拥有独立的草稿、连接元信息、API 密钥、模型默认值和自定义角色，需要按需重新配置；当前不提供自动迁移。`dualMind.language` 用户设置保留相同键名，可以继续生效。`--force` 不会跨 publisher 搬移数据。如果需要历史构建，请保留 Preview 1 原附件。

## 打开工作台

安装后按提示重载 VS Code，在命令面板运行 **DualMind: 打开工作台**（英文编辑器为 **DualMind: Open Workbench**）。该命令打开一个标签页，重复执行会定位到已有工作台；**DualMind: 显示状态**／**DualMind: Show Status** 保留为就绪检查。创建草稿前先打开文件夹或工作区；未打开工作区时仍可浏览设置和只读示例。

## 本地任务

首次打开显示空任务列表。创建任务前先打开文件夹或工作区。**新建任务**需要名称、需求和恰好一个 Reviewer 角色，保存该角色的指令快照，默认五轮，并允许为 Worker 与 Reviewer 分别选择连接和模型。API 未配齐也可以**创建草稿**。

选择已保存的草稿可查看需求和角色快照。**编辑草稿**更新文本、模型绑定及轮次上限，原有角色指令保持固定。删除需确认，仅移除任务记录，保留工作区文件、其他任务和角色预设。

草稿与选中任务按工作区保存，重新打开工作台或重载窗口后恢复。不同工作区拥有独立任务列表。未打开工作区时仍可使用设置和示例。

**查看示例**展示只读任务／对话及预期并行任务外观，**退出示例**返回真实草稿。示例不写入记录，也不发起模型请求。

## API 设置

以下查询功能适用于从源码构建的当前开发分支。已发布的 `0.0.1`／Preview 2 安装包保留原有的本地设置能力。

设置 → **API 连接**管理名称、HTTP(S) Base URL 和可选的默认模型 ID。新连接预填 `https://api.openai.com/v1`，也可填写兼容服务的 API 基础路径。首次配置顺序如下：

1. 保存名称和 Base URL，默认模型可以留空。
2. 点击**设置密钥**，在原生 VS Code 密码框中输入密钥。页面只收到保存状态。
3. 点击**测试并获取模型**。**模型列表可访问**仅确认列表接口可访问，不代表推理权限或聊天适用性已验证。
4. 搜索或选择模型 ID，也可手动输入自定义 ID，然后**保存连接**。**刷新模型**不会改变当前模型值。

打开设置或选择器不会自动请求。各连接的列表独立，仅在当前工作台挂载期间缓存。查询展示加载中、成功及数量／时间、空列表或本地化错误；失败或端点不支持列表时仍可手动输入 ID。修改 Base URL 后先保存再查询；成功修改地址／密钥或删除连接会使旧列表失效，取消替换密钥则保留旧密钥和列表。

设置 → **新任务的默认配置**为独立标签，位于“API 连接”和“Reviewer 角色”之间。在此配置 Worker／Reviewer 绑定，并点击**保存默认值**。切换标签会丢弃未保存的修改；重载恢复当前标签及已保存的值。连接自身的默认模型仍在“API 连接”页管理。

Worker 与 Reviewer 的默认绑定相互独立，新草稿继承默认值；已有草稿保留保存过的 ID，即使新列表中没有该 ID。表单主动切换连接时使用该连接的默认模型，允许为空。方向键导航候选项，Enter 选择，Escape 优先关闭列表，再关闭任务弹窗。鼠标选择后关闭菜单并保留输入焦点。

连接元信息、默认值和角色预设属于本机 VS Code 用户，可跨工作区使用。删除连接会移除密钥并清除对应默认绑定；引用它的草稿仍可编辑。凭据保存在 VS Code 秘密存储中，查询不发送任务需求或工作区内容。

## 语言与 Reviewer 定义

使用**设置 → 界面语言**，或 VS Code 的 `dualMind.language` 设置：

| 值             | 行为                                              |
| -------------- | ------------------------------------------------- |
| `auto`（默认） | 中文 VS Code 显示简体中文，其他编辑器语言显示英文 |
| `zh-CN`        | 简体中文                                          |
| `en`           | English                                           |

手动选择按用户保存并立即生效。工作台标签、提示、校验、确认框和示例内容跟随切换。原生命令名称和设置说明跟随 VS Code 自身的显示语言。

设置 → **Reviewer 角色**提供 Bug、Feature、Review、Refactor。每类分别维护英文和简体中文的用途／指令，内置名称固定并本地化。编辑或恢复只影响当前显示语言，恢复默认需要确认。Worker 保持通用执行职责。

自定义角色的名称、用途和指令保持录入时的原文，支持新增、编辑和删除。创建任务时保存选定预设及语言的快照；之后切换语言、修改或删除预设，都不追改已有草稿。因此中文界面中可能保留英文任务快照，反之亦然。

通过语言选择器切换时，普通表单保留已输入内容。若角色指令有未保存修改，会先提供**保存**、**放弃修改**和**取消**；保存会先写入当前语言版本。离开页面或重载窗口前，请明确保存表单。

## 当前限制

模型执行、流式输出、自动审查循环、提交反馈、暂停／停止、读取编辑器上下文及代码应用尚未接入，对应控件禁用，不会报告模拟成功。真实任务目前均为草稿，运行／暂停／完成状态仅存在于隔离的只读示例中。

七组[已采用设计稿](./design.md)继续保留，其中的执行状态描述后续预期行为。剩余工作见[路线图](./roadmap.md)。更新后找不到工作台命令时，请确认 `Pro-qing.dual-mind` 已安装并启用于当前 VS Code 实例，并重载窗口。
