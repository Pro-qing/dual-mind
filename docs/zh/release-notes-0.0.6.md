## 包含的能力

相对原 `v0.0.5` 标签，0.0.6 汇总后续功能提交及本轮归档的 README、本机 Python 修改：

- **紧凑任务主页：** 名称与删除双按钮，完整名称提示、键盘焦点、只读示例及删除确认；详细状态在任务详情查看。
- **工作树与成果收尾：** 隔离任务可选择本地基点；脏源目录的未提交修改不复制。用户显式提交、普通合并、处理冲突、保存清理及恢复成果；验收通过保留工作树，合入结果仍需验证。
- **角色上下文：** 按连接和模型配置窗口，Worker／Reviewer 独立预算、自动语义摘要及超限恢复；聊天、公开操作和验收证据保留，摘要不重放工具操作或清零业务预算。
- **工具错误恢复：** 预检整批拒绝，执行后首次失败跳过后续调用，错误交回当前角色；三次无进展失败暂停。命令提供结构化输出与终止原因，历史失败和当前验收阻塞分别展示。
- **离线常用命令：** Linux x64 随包提供固定版本 rg／fd／jq，优先系统命令，仅扩展任务进程 PATH，执行失败不自动换版本重跑。
- **本机 Python：** 在准备和恢复时发现实际任务环境、已激活环境及 PATH 中的 Python 2.7／3，保留验证后的调用路径与版本。两个角色通过现有 `run_command` 使用，不随包携带、下载或安装解释器。
- **产品介绍：** 中英文 README、扩展简介和真实只读示例截图围绕产品能力与上手流程；保留所有 37 组已审核设计及原归档路径。

完整行为与限制见[使用说明](./usage.md)、[生命周期](./task-lifecycle.md)、[工具错误](./tool-errors.md)、[内置命令](./bundled-tools.md)及[本机 Python](./local-python.md)。

## 支持边界

支持基线保持 Ubuntu 20.04+ x64、VS Code 1.100.0+ 和 Git 2.25+；开发与打包使用 Node.js 24。每工作区同时运行一个任务，编辑器上下文自动采集与并行执行仍未实现。模型通过用户配置的兼容 API 调用，功能不等于离线推理或保证代码正确。

本轮不运行远端 CI、其他编辑器版本、原生 Windows／macOS／ARM64、付费模型或安装／上架验证，不将它们记为通过。公开发布前按发布指南核对目标提交与 CI，公开时间及结果另行记录。
