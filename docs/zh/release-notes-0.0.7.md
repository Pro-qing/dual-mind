# DualMind 0.0.7 — 持续执行与验收诊断

[English](../en/release-notes-0.0.7.md) · [文档索引](./README.md)

**状态：本地版本准备，尚未公开发布。** 记录日期：2026-11-24。扩展标识保持 `Pro-qing.dual-mind`，推送和公开发布由维护者单独执行。

## 修改内容

- 模型往返和工具调用不再因达到 20／200 次停止；摘要和恢复保留诊断计数。审查轮数、超时、上下文、日志和重复失败控制继续生效。
- 因旧调用次数上限失败的最新运行，在恢复数据有效时支持手动继续，保留原方案、文件及已完成操作；升级不会自动启动运行。
- 验收错误明确指出未解决阻断和具体验收证据问题。`unresolved` 只记录阻断事项，范围说明及可选检查放入总结／证据，真实阻断继续生效。
- 父命令退出但仍有被跟踪子进程时，完成清理并返回 `backgroundIncomplete`，保留父进程退出码；前台验证完成后才可作为验收依据。
- 修复 Linux 短 Python 探测在读取 `/proc` 时退出产生的 `ESRCH` 时序问题，继续核验进程组清理并保留权限错误处理。
- 旧通用错误、调用上限错误和版本 1 恢复记录继续可读，既有 Debug 组件展示新双语诊断，布局保持兼容。

版本修改前修复定向测试及类型检查通过。最终 `npm run check` 通过：22 项环境、7 项资产测试，336 项本地测试中 335 通过、1 项 Windows 专用跳过，类型、lint、格式与文档检查通过。构建及 VS Code 1.100.0 扩展宿主 3 项通过；完整真实 Webview 回归通过并生成 87 张截图，原生侧栏／迁移 18 项通过。Linux 短进程修复在编辑器内置 Node.js 20.19.0 下连续 500 次探测通过。修正过程和限制见[开发日志](./development-log.md)。固定源码提交后的安装包／隔离安装核对及最终摘要写入独立制品构建记录。

本地交付 `release/dual-mind-0.0.7.vsix`、对应 `.vsix.sha256` 及 `dual-mind-0.0.7-build.json`。最终干净提交及本地附注标签 `v0.0.7` 标识源码，README 链接固定到该标签，推送标签后远端链接才可访问。旧安装包以及 debug 任务工作树／日志保留。操作见[发布说明](./releasing.md)。

## 支持边界

支持基线仍为 Ubuntu 20.04+ x64、VS Code 1.100.0+ 和 Git 2.25+，开发使用 Node.js 24。本地 Linux 测试不代表原生 Windows／macOS／ARM64、远端 CI 或付费模型已验证。进程跟踪保留已记录的逃逸进程限制，成果审阅和公开发布仍由维护者执行。
