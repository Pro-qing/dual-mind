## 包含的修改

- 完整工作台迁至原生侧栏：保留打开／新建／选择任务命令，支持主侧栏或辅助侧栏及用户保存的位置，增加手动“终端仅占编辑器区域”。
- 页面隐藏或移动时执行服务继续运行；显示时补齐记录，异步回复绑定页面实例。旧页签迁移显示状态，已有侧栏状态优先，初始化失败可重试。
- 紧凑导航、单列设置、可折叠任务详情、填充剩余高度的聊天及底部输入框；保留输出最小化、错误和继续执行。
- 纳入此前已实现的通用 shell、Reviewer 独立验证、任务命名和可靠恢复。基础工具链要求、角色权限、执行协议和数据版本不变；依赖版本不变。
- 设计稿按版本归档，[总索引](../design/README.md)映射 27 组图稿。0.0.3 目录包含初始标签后的同版本修订；本次不移动任何历史标签。SVG／PNG 内容逐文件核对 SHA-256，保持原样。
