## 本版变化

- **模型接入：** 独立选择 OpenAI 兼容／Command Code Provider 及 Chat Completions、Responses、Anthropic Messages 协议；地址、提供商或协议改变后先保存再查询模型。密钥由 VS Code 宿主保存，手动模型 ID 继续可用，旧客户端保存保留已有配置及模型窗口。
- **双角色审查：** Reviewer 只读规划、答疑和审查，以 pass／fail、风险、信心、问题与证据返回结论；Worker 实施修改并执行命令。宿主校验结束协议和成果一致性，失败命令作为 Reviewer 判断材料。
- **紧凑界面：** 标题和主要操作集中排列，上下文／成果面板并排且互斥展开。聊天和证据先按用户请求，再分别按 Reviewer、Worker 和系统记录折叠；历史无 ID 记录仍可阅读。
- **主题与窄窗口：** 背景、控件、选中态、角色和错误提示跟随当前 VS Code 主题；支持浅色、深色及两种高对比度。240px 侧栏展开详情时为输入框保留空间，修正浅色高对比度选中文字。
- **持续阅读：** 分页携带原始请求及处理状态，同文不同 ID 不合并；折叠、滚动和面板偏好分别保存，消息已处理不等同任务验收通过。保留恢复、成果操作和模型私有历史隔离。

场景 38–40 于 2026-11-25 审核通过，并要求背景与主题一致。图稿仍位于原 `docs/design/v0.0.7/` 开发目录；0.0.8 包含全部 40 组已审核 SVG／PNG，不移动原图或历史标签。
