# DualMind 0.0.3 — 执行与分支选择版

[English](../en/release-notes-0.0.3.md) · [文档索引](./README.md)

**状态：本地源码版本，尚未发布。** 记录日期：2026-11-20；本地附注标签：`v0.0.3`；扩展标识仍为 `Pro-qing.dual-mind`。此日期是本次补录／整理日期，不是历史公开时间；本地 VSIX 可按开发指南生成，尚未上传 Marketplace 或创建 GitHub Release。

## 变化

- 增加 Chat Completions／Responses 流式推理及工具调用适配；Worker／Reviewer 使用独立历史和固定执行快照。
- 打通 Reviewer 规划、Worker 自主实施和命令验证、Reviewer 验收及下一轮方案循环，支持轮次限制、暂停／继续／停止、反馈和重载中断。
- 增加活动栏图标、原生任务侧栏、公开流式输出、检查证据、分页记录、差异预览及目录入口。
- 新任务可选专用分支、当前分支或指定已有本地分支；直接模式每次执行前检查目录干净，固定分支与 HEAD，查看记录不切分支。
- Reviewer 无写入和命令工具；命令直接在任务目录中执行，不依赖 systemd/cgroup 或固定内存／交换空间配额；保留超时、输出上限和进程组停止。

- 稳定真实 Webview 截图辅助逻辑，避免提示条自行消失后继续等待关闭按钮。

继承 [0.0.2 基础能力](./release-notes-0.0.2.md)。当前每工作区仅一个活动任务；不会自动提交、stash、fetch、合并或推送。Worker 可按方案准备项目依赖，不自动安装系统工具链。专用目录成果由用户处理；直接模式不在停止／删除时回滚文件或自动切回原分支。并行任务、自动编辑器上下文和专用成果自动应用仍未实现。

## 兼容与环境

草稿／配置存储版本保持 1，不执行数据迁移。扩展版本与存储版本分别管理；依赖版本不变。 旧连接缺省使用 Chat Completions，旧任务缺省使用专用分支。任务命令按 Linux 基线执行；目录和命令都不是操作系统沙箱。
