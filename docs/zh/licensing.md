# 许可状态

[English](../en/licensing.md) · [文档索引](./README.md)

仓库所有者尚未选定许可证。目前没有 `LICENSE` 文件，npm 元信息明确使用 `"license": "UNLICENSED"` 和 `"private": true`。仓库公开可见并不代表已授予开源许可。

选定许可证后，需要同步更新许可文本、包清单、两份 README、贡献说明和本文档。依赖项保留各自的许可证，根目录的许可元信息不会替代依赖许可。本骨架不引入贡献者协议或版权转让条款。

本地 VSIX 打包仅为开发验证跳过缺失许可证检查。公开分发前应先确定许可证，移除该跳过设置，并完成[发布清单](./releasing.md)。
