# 宿主与 Webview 通信协议草案

[English](../en/protocol.md) · [文档索引](./README.md)

**状态：仅设计说明，当前没有运行中的消息协议或稳定公开 API。**

当前公开入口为命令 `dualMind.showStatus`，不接收参数，仅显示骨架状态。扩展生命周期由 VS Code 管理。

## 规划中的消息方向

| 方向           | 意图                                                       |
| -------------- | ---------------------------------------------------------- |
| Webview → 宿主 | 开始任务、暂停或停止会话、提供人工反馈、请求结果预览或应用 |
| 宿主 → Webview | 会话状态、Worker/Reviewer 输出、审查结果、可处理的错误     |

宿主负责调度、模型调用、取消和编辑器操作，React 界面负责呈现宿主状态。模型服务调用失败与审查不通过应明确区分。

实现前需在 `src/shared/` 定义实际消息类型，在宿主边界验证 Webview 输入，并确定会话关联和取消语义。凭据保存在宿主的秘密存储中，不通过 Webview 消息传递。设计稿中的模型名称仅为标识，尚不定义凭据配置界面。

字段名、负载结构、传输版本、模型适配 API 和持久化方式将在设计获批及首个可运行会话需要时确定。修改本草案时同步维护两种语言。
