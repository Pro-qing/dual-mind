# React workbench / React 工作台

The React/TypeScript Webview has separate task home and detail pages, shared task forms, settings, a typed bridge, and responsive styles. Creation opens a pending task; execution starts manually. Detail uses compact model bars, task chat, independent evidence and a persistent composer. Below 1100 CSS pixels, evidence appears in a drawer. Questions and continued changes reuse the task conversation. The host owns persistence, credentials, model requests, and the execution loop. Structured errors are formatted in the current language; original details and command output remain available. Read-only examples are isolated from saved tasks. See [Usage](../docs/en/usage.md), [Architecture](../docs/en/architecture.md), and [Designs](../docs/en/design.md).
